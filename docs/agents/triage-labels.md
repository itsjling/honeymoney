# Triage labels

| Canonical role    | Tracker label      | Meaning                                |
| ----------------- | ------------------ | -------------------------------------- |
| `needs-triage`    | `needs-triage`     | A maintainer must assess the issue     |
| `needs-info`      | `needs-info`       | Waiting for more details               |
| `ready-for-agent` | `ready-for-agent`  | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human`  | Requires human implementation          |
| `wontfix`         | `wontfix`          | Will not be acted on                   |

When a skill names a canonical role, use the matching tracker label.
