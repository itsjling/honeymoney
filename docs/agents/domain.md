# Domain docs

## Layout

This is a single-context repo.

## Before exploring

Read:

- `CONTEXT.md` at the repo root.
- ADRs under `docs/adr/` that touch the work area.

If a file does not exist, continue without comment. Producer skills create domain docs when the team resolves terms or decisions.

## Use the glossary vocabulary

Use terms from `CONTEXT.md` in issue titles, plans, tests, and other output. Do not replace them with synonyms that the glossary says to avoid.

If a needed concept is missing, reconsider the term or note the gap for domain-modeling work.

## Flag ADR conflicts

Call out any conflict with an ADR instead of overriding it without notice.
